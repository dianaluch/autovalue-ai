## Модель предсказания стоимости подержанных автомобилей
```
Цель - построить модель регрессии, которая прогнозирует стоимость автомобилей по их характеристикам
и региону продаж с учетом бизнес-рисков переплаты и недооценки.
```
### Модели

Сравнены три алгоритма градиентного бустинга, c последующим подбором гиперпараметров через Optuna:

- XGBoost
- LightGBM
- CatBoost

Результаты на валидационной выборке:

| Модель   | МАЕ, руб. | RMSE, руб. | R<sup>2</sup> | Overpricing rate | Underpricing loss, млн руб. |
|:---------|:---------:|:----------:|:-------------:|:----------------:|:---------------------------:|
| CatBoost |  79 239   |   98 788   |     0,856     |      13,3 %      |            16,71            |
| LightGBM |  80 043   |  100 517   |     0,851     |      13,4 %      |            18,31            |
| XGBoost  |  80 265   |  100 864   |     0,850     |      13,5 %      |            19,21            |

где Overpricing rate и  Underpricing loss - бизнес-метрики:
* _Overpricing rate_ (завышение стоимости) показывает вероятность приобретения автомобиль выше его фактической рыночной стоимости;
* _Underpricing loss_ (занижение стоимости) — объем упущенной прибыли из-за непривлекательного ценового предложения для клиента.

### Датасет
Датасет содержит 10 000 наблюдений о подержанных автомобилях:

* `8 000` наблюдений для обучения;
* `2 000` наблюдений для финального тестирования;
* `13` входных признаков;
* `price_rub` целевая переменная.

### Итоговые результаты
В качестве финальной модели выбран оптимизированный CatBoostRegressor со следующими результатами на тестовой выборке:

| Метрика                     | Результат |
|:----------------------------|:---------:|
| МАЕ, руб.                   |  75 530   |
| RMSE, руб.                  |  94 583   |
| R<sup>2</sup>               |   0,875   |
| Overpricing rate            |  12,9 %   |
| Underpricing loss, млн руб. |   19,74   |

Для интерпретации модели и определения признаков, оказывающих наибольшее влияние на прогноз стоимости, использовался SHAP.
Пять наиболее важных признаков:

1. `engine_cc`
2. `make_year`
3. `owner_count`
4. `fuel_type`
5. `mileage_kmpl`

```
Модель выявила несколько интуитивно понятных закономерностей:

- больший объём двигателя, как правило, увеличивает прогнозируемую стоимость;
- более новые автомобили имеют более высокую прогнозируемую стоимость;
- большее количество предыдущих владельцев снижает прогнозируемую стоимость;
- тип топлива влияет на стоимость; наибольший вклад характерен для электромобилей;
- высокая топливная экономичность повышает стоимость автомобиля.
```
Ошибки прогнозирования дополнительно анализировались по маркам автомобилей и регионам продаж.  
Наиболее проблемными зонами являются `BMW`,`Tesla` и `Volkswagen`, поскольку они имеют высокие 
значения Underpricing loss, а `BMW` и `Tesla`также характеризуются одним из самых высоких MAE.
По регионам особого внимания требуют `СПб` и `Юг`, где зафиксированы наибольшие суммарные потери 
от недооценки. 


### Этапы проекта

Проект включает следующие этапы:
1. Исследовательский анализ данных (EDA);
2. Предобработка данных;
3. Обучение базовых моделей XGBoost, LightGBM и CatBoost;
4. Оптимизация гиперпараметров с использованием Optuna;
5. Интерпретация и бизнес-анализ (SHAP);
6. Обучение финальной модели и оценка на тестовой выборке.
